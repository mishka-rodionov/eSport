# Workflows

Императивные процессы для Claude Code: «когда X — делай Y». Каждый файл описывает конкретный класс задач (создание экрана, добавление фичи и т.п.) и **обязательные** шаги, которые Claude должен выполнить.

Подключаются через триггеры в корневом [CLAUDE.md](../../CLAUDE.md). Сами файлы автоматически в контекст не загружаются — Claude читает нужный воркфлоу через Read, когда триггер сработал.

## Доступные

- [analytics.md](analytics.md) — добавление аналитики при создании новых экранов и пользовательских действий.

## Когда добавлять новый workflow

Когда замечаешь, что Claude систематически промахивается на каком-то типовом сценарии (забывает шаг, нарушает архитектуру, не задаёт нужный вопрос) — это сигнал, что нужен новый workflow. Не пытайся описать всё заранее.
