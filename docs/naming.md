# Нейминг приложения

Заметки по подбору названия для мульти‑спорт платформы (организация событий, соревнований, тренировок, активностей).

## Требования

- Не привязано к ориентированию (планируется расширение на другие виды спорта)
- Хорошо звучит как доменное имя (латиница, короткое)
- Маркетингово сильное, легко произносимое

## Финалисты

### Eventra

- **Звучание:** мягкое, плавное, «event» + текучее «‑ra».
- **Смысл:** прямая отсылка к events.
- **Конфликт:** `eventra.app` занят немецким продуктом **EVENTRA — AI Workforce Management для крупных мероприятий** (прямая ниша). `eventra.com`/`.io`/`.ru`/`.co` также заняты.
- **Вердикт:** ⚠️ острый конфликт по нише — брать «как есть» рискованно.

### Recora

- **Звучание:** короткое, мелодичное, энергичное «r».
- **Смысл:** от *record* — фиксация результатов и протоколы.
- **Конфликт:** `recora.com` — Aviary Health (бывш. Recora, медтех); `recora.io` — AI‑стартап «Recora.io»; `recora.ru` — действующая российская дизайн‑студия «Рекора».
- **Вердикт:** ⚠️ конфликт на ключевом рынке (РФ).

## Свободные доменные альтернативы (по DNS)

| Домен | Статус | Комментарий |
|---|---|---|
| **eventra.run** | ✅ свободен | Идеально для спорта: «event» + «run» |
| **recora.run** | ✅ свободен | TLD сам становится частью бренда |
| **recora.dev** | ✅ свободен | Tech‑позиционирование |
| **recora.tech** | ✅ свободен | Tech‑позиционирование |
| **eventria.app** | ✅ свободен | Производная от Eventra |
| **reckora.app** | ✅ свободен | Recora с твёрдым «k» |
| **recoria.app** | ✅ свободен | Близко к Recora, без коллизий |
| **recoro.app** | ✅ свободен | Короче, мужественнее |

## Рекомендации

1. **eventra.run** — если идём с Eventra; TLD `.run` обыгрывает спорт и обходит конфликт.
2. **recora.run** — то же для Recora; «recora.run» = призыв к бегу.
3. **Reckora** (на `.app`/`.com`) — самое чистое решение: сохраняет фонетику Recora, без бренд‑конфликтов.

## Резерв (длинный шорт‑лист)

Чтобы не терять контекст обсуждения:

**Связано с событиями:** Eventra, Eventify, Hosta, Stagora, Festora, Convenia, Lineora, Slotix.
**Состязания:** Arenia, Tornia, Champra, Versora, Heatra, Bracketa, Leagora, Vitora.
**Тренировки/активности:** Trainora, Aktora, Pulsora, Movora, Sessia, Drilla, Coachly.
**Результаты/хронометраж:** Lapora, Finora, Splitora, Recora, Trackora, Tempora.
**Универсальные:** Sportora, Joinix, Eventa, Compio, Velora (сильная корреляция с велотемой в РФ — отвергнуто).

## Следующие шаги

- [ ] Финализировать выбор из 3‑х (например: eventra.run / recora.run / Reckora)
- [ ] Проверить товарные знаки: Роспатент (РФ), EUIPO (ЕС), USPTO (США)
- [ ] Проверить занятость социальных хэндлов: Instagram, Telegram, X, YouTube
- [ ] Зарегистрировать выбранный домен + защитные TLD (.com/.app/.ru)
