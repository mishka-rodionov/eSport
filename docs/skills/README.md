# Skills

Справочные документы и конвенции для Claude Code. Сами по себе ничего не предписывают — на них ссылаются [workflows](../workflows/README.md).

Workflow говорит **«что и в каком порядке делать»**, skill — **«как это должно выглядеть»**.

## Доступные

- [analytics-events.md](analytics-events.md) — конвенции имён и параметров аналитических событий.
